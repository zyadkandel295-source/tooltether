# Roadmap

## 0.1 alpha release gates

- Confirm name, owner identity, URLs, and security contacts.
- Run official installed-SDK matrices for MCP, LangChain, CrewAI, AutoGen, and smolagents.
- Run Python 3.11–3.14 and Windows/macOS/Linux CI.
- Review coverage, security scans, build/install smoke tests, and benchmark results.

## Sensible later work

- Redis-compatible distributed cache, rate, idempotency, and concurrency backends.
- Stronger DNS resolution/rebinding policy hooks and process-isolated execution.
- Richer storage migrations, backup/restore tooling, and audit signing.
- Application-supplied cache freshness feedback and constrained retry recovery analysis.
- More adapter import paths only after upstream APIs stabilize and compatibility tests exist.
